Seasonal Agriculture Performance Analysis 🌾
VOIS AICTE Major Project — Batch 1, 2026-2027

A data analysis project exploring how farm performance (yield, profit, water use, and disease risk) varies across India's three major growing seasons: Kharif, Rabi, and Zaid.

📊 Overview
This repository contains a Jupyter Notebook that analyzes a dataset of 4,000 farm records across 8 Indian states and 8 crops. The goal is to go beyond basic data summaries to understand why seasonal profitability and yields differ, providing practical, data-driven agricultural takeaways.

🔍 Key Insights Explored
Environmental Conditions: Comparing rainfall, temperature, and humidity across seasons.

Yield vs. Profit: Analyzing the gap between production volume and actual financial return.

Risk Analysis: Identifying the percentage of farms operating at a loss per season.

Disease & Pest Pressure: Correlating pest risks with weather conditions like rainfall and humidity.

Irrigation Efficiency: Comparing the profitability and water efficiency of Drip, Flood, Rainfed, and Sprinkler methods.

🛠️ Tech Stack
Language: Python 3

Data Manipulation: Pandas, NumPy

Data Visualization: Matplotlib, Seaborn

Statistical Analysis: SciPy (ANOVA testing)
